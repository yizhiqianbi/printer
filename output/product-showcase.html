Product Flow

从热点捕捉到作品发布，压成一条 remix 流水线。

用户不需要从空白项目开始。选择一个已有玩法，描述想要的主题和包装，系统会保留关键机制，生成一个新的可玩版本。

01 选择玩法母版 从 Playable Catalog 挑选一个已经可玩的小游戏，比如停车解堵、六角弹出、三连清或测评卡。
02 输入 prompt 或语音 描述主题、场景、角色和传播梗。API 会把输入转成结构化生成意图。
03 生成草稿 保留原玩法爽点，同时改写文案、视觉包装、关卡设定和 agent description。
04 即时预览 在浏览器里试玩新版本，检查节奏、触控、状态反馈和移动端展示。
05 发布为作品 发布为新的可玩网页，写入 remix manifest，继续进入 Catalog 被浏览和再二创。

Highlights

它更像创意验证台，不是普通 H5 模板集合。

重点不是把页面做得像，而是把玩法、节奏、传播点和二创链路一起沉淀下来。

玩 输出可试玩作品，不停在概念稿。 每个结果都能直接打开、点击、失败、重开和分享，适合快速评审和投放前测试。
接 API 串起草稿、任务和发布。 Remix 按钮连接真实生成流程，支持同步草稿、异步任务和作品发布。
记 Agent description 让二创可延续。 发布时沉淀玩法说明、状态模型和演化方向，下一次 remix 可以继承上下文。
热 热点玩法持续扩展。 螺丝、挪车、排序、三消、测评、.io 和玄学卡等机制可以被快速复刻成素材池。
轻 单文件优先，方便分发。 大多数产物是离线网页作品，没有复杂运行环境，适合内部演示、活动页和内容实验。
改 换主题不丢核心手感。 系统关注机制骨架，比如“只能点前排”“三件即清”“顺箭头出块”，避免只做表面换皮。

Remix Cases

同一个玩法，可以长出不同的内容包装。

这些案例都来自当前 Remix Gallery。左侧切换玩法，右侧呈现母版、二创方向和对应 prompt。

夜班进厂通车

把当前热词“挪车打螺丝”包装成夜班厂门场景，保留点车顺车头滑动、先清门口短车、再放后排长车的节奏。

Prompt: 把今天热门“挪车打螺丝”盘改成夜班进厂通车主题，保留点车顺车头挪位、先清门口短车再放后排长车。

API Surface

前台是 Feed，后台是一套可编排的 remix 生成接口。

Remix Harness 把页面按钮接到本地生成服务。生成草稿后可以预览、编辑 agent description，再发布为新的 HTML 和 manifest 记录。

DRAFT /api/remix/draft
JOBS /api/remix/draft-jobs
PUBLISH /api/remix/publish
OUTPUT output/<slug>.html + remix_manifest.json
